# Public reproducible replay

This is the static GitHub Pages edition of CAUSALOS. The canonical application source is `causalos/web`; this directory is generated by `python examples/build_demo.py`.

- The six built-in profiles and effect analyses are executed in Python at build time. The browser only returns an analysis when both its dataset and its full question configuration exactly match the recorded fixture. Edited assumptions, graphs, adjustment sets, or data cannot reuse that result.
- Four-model and eight-model experimental replay recompute posterior probabilities, Gaussian quadrature utility, and affordable experiment rankings in JavaScript. An independent evaluator supplies recorded Python observations by scenario, action, and repeat after the action is chosen. The policy functions never receive a ground-truth model index or true causal effect.
- The evaluator bank covers recorded seed 42, budgets of 12, and all supplied action sequences. New random seeds, custom datasets, structure learning, and new fitted estimates require the local Python application.
- Counterfactual comparisons implement the canonical four-SCM abduction/action/prediction formula for a hypothetical simulated unit. They do not predict an uploaded participant’s individual outcome.
- Exported reports include current model states, recorded analyses, assumptions, and the build’s source hashes and Python/scientific package versions. Reports escape user text.

The adaptation is numerically equivalent within floating-point tolerance, not bit-for-bit identical. An acquisition ranking may differ when multiple expected gains are effectively zero. Seven cross-language sequence checks had maximum absolute posterior/effect/utility error `3.70e-16`; one acquisition tie was below `1e-24`. All claim and model-risk decisions matched.

Rebuild and verify with Python 3.11+ and Node 20+:

```sh
python examples/build_demo.py
node docs/demo/check_parity.cjs
```

The build manifest records the Python and scientific package versions, all analysis/data/web source hashes, and every generated artifact hash. The dependency-free Node check rejects stale sources or artifacts, verifies that copied canonical assets match, checks the installation link, and validates seven arbitrary action sequences against executed Python states, all six built-in analyses, 18 changed-data/graph/assumption rejections, and report escaping. The evaluator bank is isolated from policy inputs in code; because this is an open static demo it is publicly inspectable and is not a security boundary.

Browser smoke verification used the actual static replay: initial models loaded; intervention changed beliefs and budget; counterfactual predictions rendered; family challenge initialized and advanced; bundled regression/IPW/AIPW/DML results rendered; changing exchangeability cleared those results and blocked a new estimate.
