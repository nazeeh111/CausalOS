# Reproducible case studies

`causalos example confounded --out artifacts/example` writes observed data, a question file and source metadata. Other examples are `randomized`, `hidden_confounding`, `nonidentifiable`, `collider` and `nsw`.

The synthetic generators keep truth in evaluator metadata rather than feature columns. Invalid examples deliberately abstain. The real example contains 445 actual National Supported Work records from the Dehejia–Wahba restricted randomized sample, including 185 treated and 260 control observations. It is distributed by the MIT-licensed causaldata package. The canonical source, checksum, removed label columns and copyright are preserved in [packaged provenance](../causalos/resources/data/nsw-provenance.json) and [license](../causalos/resources/data/CAUSALDATA_LICENSE.txt). Earnings are historical 1978 dollars; no true individual or population treatment effect is observed.

`analysis-results.json` and its figure were generated by `evaluate.py`:12 independent synthetic seeds per eligible case, declared-invalid abstention checks, an intentionally incorrect-assumption stress test, the actual NSW analysis and ten dependent row splits of one IHDP replication. [Methods, results and their limits](../docs/analysis.md) explain the scope. In particular, unrecorded hidden confounding plus falsely confirmed assumptions defeated the observational validity gate in 12/12 stress cases.

IHDP replication1 is an established semi-synthetic benchmark. Upstream CEVAE does not declare a dataset license, so its raw records are not redistributed. `fetch_ihdp.py` retrieves exact public bytes and verifies the recorded checksum. Assess upstream terms for your intended use.

```bash
python examples/fetch_ihdp.py /tmp/causalos-ihdp.csv
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python examples/evaluate.py --ihdp /tmp/causalos-ihdp.csv --seeds 12
```

Leave out `--ihdp` to run the fully bundled synthetic/NSW studies. The Python audit API provides explicit transformations without mutating the input:

```python
from causalos.profiling import audited_transform
changed, audit = audited_transform(data, [{"op": "drop_missing", "columns": ["Y"]}])
```

Dropping missing outcomes can change the target population and induce selection bias. Record the returned audit and reassess the study assumptions before using transformed data. See the function's supported operation schema in `profiling.py`.
